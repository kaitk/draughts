# 080: One new game on home, and settings looked at afresh

Status: in-progress

Home offers two ways into a game, A friend and The computer, each a row. A friend on a
tablet is rare: it was the only way to play before the computer player existed (the
user, 2026-11-13). Home gets one row for a new game, and the opponent is chosen on the
next screen, the setup, where the board's turning for a friend's game moves too: it is a
choice about that game, not a look, and in settings it reads as if it always applied.

With the turning gone from settings, the screen is looked at afresh, and it gains a new
choice: each season's 3D board in wood or stone, or the season's own (auto). Settings and
home's menu may scroll now where scrolling is plain to see, rather than packing every
choice into one view behind tabs; on a small screen the preview may give up room.

Prototyped first (`prototypes/new-game.html`, `prototypes/settings-takes.html`), the
user choosing; then built.

## Subtasks

- `01-new-game.md`: home's one New game row, the setup with the opponent and the turning
- `02-settings.md`: settings reworked, scrolling where it helps, the preview smaller on a
  small screen
- `03-board-materials.md`: wood, stone, carved, or auto for the 3D board, two new looks
  (autumn's stone, winter's wood) and summer's stone finished; replaces task 045
