# 043: iOS

Status: in-progress

The app on iPhone and iPad through SDL on UIKit, drawing with SDL_GPU on Metal
([architecture](../docs/architecture/README.md): "Other platforms on SDL"), built by
`scripts/ios.py` without an Xcode project (`docs/development.md`). Done 2026-11-09 and
10: the simulator (2D, 3D, both languages, the safe area, background and foreground),
rotation (`patches/SDL/0006`), and a development build on the iPhone 13 mini with touch.

What to keep in mind: each data stack is reserved at 128 MB (`--stack-reserve 128M`), so a
stack that outgrows it stops the program; iOS kills an app that submits GPU work in the
background, so the loop draws nothing between `WILL_ENTER_BACKGROUND` and the foreground.
